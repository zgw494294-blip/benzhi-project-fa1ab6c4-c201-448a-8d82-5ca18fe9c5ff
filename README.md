# 地震台站仪器校准证书治理服务

本项目为地震台站计量技术员、校准复核员和质量负责人提供完整的校准放行链路：建立仪器与标准器档案，录入测量点并自动计算误差和不确定度，处理超差偏差，完成同行复核，冻结结果并签发带校验码的不可变证书。服务同时提供响应式原生 Web 工作台和同源 HTTP JSON API，所有业务事件写入带哈希链的本地 JSON Lines 日志，并通过原子快照支持重启恢复。

## 构建、运行和测试

```text
go test ./...
go run ./cmd/server -addr=127.0.0.1:19081
```

默认监听 `127.0.0.1:19081`。也可以使用 `-addr=127.0.0.1:<port>`，或者设置 `PORT` 端口号（服务会绑定到 `127.0.0.1:<PORT>`）。数据默认保存在 `.data`，可通过 `-data-dir` 指定。

执行端到端自检并自动退出：

```text
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck
```

任务详情页支持必测点位方案、覆盖率检查、批量测量预检与原子提交、分类批量整改、退回修订差异和结构化复核清单。证书资源支持作废登记（`POST /api/certificates/{number}` 或 `/void`），公开校验会联动作废状态；`GET /api/system/integrity` 同时返回事件仓储与证书哈希链连续性报告。
